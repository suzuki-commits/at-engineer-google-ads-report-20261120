1. 結論

目標の水準は、今年7月に同じアカウントで既に出ていました（CVR 5.77%・CPA 16,609円）。やるべきことは「新しい打ち手を探す」より先に「7月の状態に戻して固定する」ことです。

コンバージョン率（CVR）を1.5倍にすると、クリック単価が同じなら CPA は自動的に3分の2になります。つまり目標は実質1つで、CVR 3.58% → 5.4%（クリック単価 970円を維持）です。

8月以降に悪化した要因として管理画面から確認できたのは、①入札戦略の頻繁な切り替え（約3か月で15回）、②キャンペーン終了日切れによる配信停止（8月に2回）、③成果の出ていたキーワードの削除・停止、④関係の薄い検索語句への配信、の4つです。クリエイティブ（広告文）の更新頻度は確かに低いものの、それだけでは目標に届かない、というのが検証結果です（5章）。

3. 悪化の原因（管理画面で確認できた事実）

原因1　入札戦略を約3か月で15回切り替えている

7月は「目標コンバージョン単価 20,000円」で固定されており、実績 CPA は16,609円でした。7月28日以降、目標の解除と再設定が繰り返されています。

日付 キャンペーンの入札設定の変更
7/28 目標CPA 20,000円を解除
8/3 目標CPA 20,000円を再設定
8/16・8/18・8/19 解除 → 再設定 → 解除（4日間で3回）
8/21 最適化案の自動適用で目標CPA 22,684円に
9/1 20,000円へ引き下げ
9/23・10/1 解除 → 20,000円で再設定
10/15・10/19・10/21 解除 → 25,000円 → 28,000円
10/29・10/30 解除 → 「クリック数の最大化」へ変更
11/2 「コンバージョン数の最大化」＋目標CPA 28,000円へ戻す

自動入札は設定を変えるたびに学習をやり直します。週のコンバージョンが2〜10件のこのアカウントでは、平均6〜7日おきの変更だと学習が終わる前に次の変更が入ります。「クリック数の最大化」にした10/26の週は、クリック357に対して CVR 1.31%でした。

同じキーワード「フリー ランス 仕事 在宅」でも、CVR は7月 7.25% → 9月 3.67% → 10月 1.99%と下がっています。キーワードの入れ替えではなく、配信の質そのものが落ちたことを示します。

原因2　キャンペーンの終了日切れで8月に2回止まった

終了日が7/31と8/12に設定されており、延長されたのはそれぞれ8/3朝と8/16未明でした。8/1〜8/3と8/13〜8/15の2回、配信が止まっています（表示回数もゼロ近くまで落ちています）。8月のコンバージョンは24件で、7月の60件から6割減りました。

終了日は9/28に「終了日なし」へ変更済みです。

原因4　関係の薄い検索語句に広く配信されている

4,111クリックに対して検索語句は17,431種類あります。主力キーワードの多くが「インテント マッチ」（最も広い一致）で、次のような語句にも広告が出ていました。

転職・求人媒体名：ビズリーチ、indeed、リクナビ、マイナビ、ランスタッド、エンゲージ　／　職種違い：動画編集 業務委託、完全在宅 データ入力 業務委託、高収入 求人、仕事 探し、スキル 販売、ココナラとは

これらの一部（ビズリーチ 4.5件、indeed 1件など）は登録まで進んでいますが、フリーランス案件を探すエンジニアではない可能性が高く、登録後の面談・参画につながっているかは管理画面からは分かりません。除外キーワードの追加は46回中39回が10〜11月に集中しており、それ以前はほぼ手つかずでした。

原因5　リンク先ページが3回入れ替わり、広告文とページの内容が合っていない

全広告のリンク先が、登録ページ（/register）とトップページ（/）の間で 7/16・8/16・10/2 の3回切り替えられています。切り替えと同時期に入札変更や停止も起きているため、どちらが良いのかは判定できません。

要確認　コンバージョンの計測状態

主計測の「登録完了(Mypage/initial)」（144件）のステータスが「要確認」、他2つが「設定が不適切」と表示されています。計測もれが起きているなら、8月以降の CVR 低下の一部は実態ではなく計測の問題です。社内の登録データと月別に突き合わせることを最初に行ってください。また、企業向けの「企業開拓 申し込み完了」がメインの目標に混ざっています。

5. 検証：「クリエイティブを高速で回せば目標を達成できる」か

判定：半分は正しい。更新頻度は確かに低く、上げるべきです。ただしクリエイティブだけでは CVR 1.5倍には届かず、順番を誤ると効果も測れません。

仮説を支持する材料

  • 広告文の更新は6週間に1回、比較テストはゼロ。改善の余地は大きい
  • 11/4に新しい切り口で作った「転職・働き方比較」は CVR 10.91%・CPA 14,000円（ただしクリック55・CV6件と少数）
  • 費用の47%を占める「案件探し」「競合」の広告の有効性が「平均的」「低い」
  • 競合グループのクリック率は2.01%と低く、品質スコア低下の表示が多数

仮説だけでは足りない理由

  • 目標水準を出した7月は、広告文を一切変えていない。悪化の原因は広告文の外にある
  • 10/14の書き換え後、クリック率は9月5.34% → 10月3.56%に下がり、CVRも改善していない（同時期の入札変更と分離できない）
  • 広告文が主に動かすのはクリック率で、CVRはページとフォーム、流入の質で決まる部分が大きい
  • クリック数が少なく、テストの判定に時間がかかる（下記）

「高速」の現実的な上限

現在のクリックは月500前後です。CVR 3% → 4.5% の差を統計的に確かめるには1案あたり約2,500クリックが必要で、アカウント全体の4.7か月分（4,111クリック）を超えます。つまりCVRで広告文の勝ち負けを素早く判定することはできません。クリック率で判定する場合も、4.5% → 5.4%の差を見るのに1案あたり約9,000回の表示が必要で、最大グループ（月約6,600回表示）で1テストに約3か月かかります。

したがって「高速」は、細かい言い回しを大量に試すことではなく、訴求の切り口が大きく違う2案を、主要3グループで3〜4週間ごとに入れ替えるという形が現実的です。入札とリンク先を固定した状態でないと、結果は読めません。

試算必要数は、有意水準5%・検出力80%での一般的な計算による概算です。

6. 目標までの道筋（試算）

打ち手 CVRへの効果（見込み） 根拠
A. 入札の固定・停止の防止・主力キーワードの復旧 × 1.25 7月（5.77%）と期間平均（3.58%）の差の半分が戻ると仮定
B. 検索語句の整理（除外と一致の絞り込み） × 1.10 関係の薄いクリックを1割減らすと仮定
C. ページとフォームの改善 × 1.10 広告とページの一致、入力項目の削減
D. クリエイティブの継続テスト × 1.05 ほかにクリック率 +10〜20% を見込む
合計 × 1.59 CVR 3.58% → 約5.7%、CPA 約17,000円（クリック単価970円の場合）

試算倍率は筆者の仮定で、実測値ではありません。Aが最大の要素で、ここが戻らなければ B〜D を足しても目標には届きません。

CPAが18,100円以下で2週間安定したら、日予算を2週間ごとに20%ずつ上げてコンバージョン数を伸ばします。Googleの比較表示では、類似ビジネスの週あたりクリックは1,434（当アカウントは135）で、配信を増やす余地はあります。

7. 具体的にやること

今週中（1〜3日）

止血と土台の固定

  1. 計測の確認。社内の登録件数（7〜11月・月別）と管理画面の147件を突き合わせる。「登録完了」タグの「要確認」を解消し、「企業開拓 申し込み完了」をメインの目標から外す。
  2. 入札戦略を固定。「コンバージョン数の最大化＋目標CPA 28,000円」のまま、最低4週間は戦略の種類を変えない。目標値を動かすのは2週間に1回まで、幅は15%以内とする。
  3. 主力キーワードを戻す。「フリーランス 仕事 在宅」をフレーズ一致で再登録する。社名「アットエンジニア」の検索に広告が出ているかを確認し、出ていなければ完全一致で再開する。
  4. 自動で変わる設定を止める。最適化案の自動適用は11/13に一部停止済み。キーワードの自動追加と目標CPAの自動変更が残っていないか確認する（11/2〜11/8にも2件自動適用されています）。
  5. 終了日と残高。キャンペーンの終了日が「なし」のままか、支払い残高で止まらないかを確認する。
1〜2週目

お金の流れ先を直す

  1. 除外キーワードを一括登録。転職・求人媒体名、クラウドソーシング名、エンジニア以外の職種（データ入力、動画編集、デザイナー、派遣、日雇い、アルバイト）を共有の除外リストにして全グループへ適用する。
  2. 広すぎる一致を絞る。CPAが4万円前後の「エンジニア 求人」（費用203,913円・CPA 40,783円）、「フリーランススタート」（CPA 45,723円）、「日雇い エンジニア」（CPA 45,027円）はフレーズ一致へ切り替えるか停止する。
  3. 成果ゼロの出費を止める。費用1万円以上でコンバージョン0件のキーワード（フルリモート 業務委託、フリーランス エージェント エンジニア、PE-BANK、エンジニアスタイル、php リモート 案件、c++ 求人 など、合計約13万円）と Java グループを停止する。
  4. 成果の良い語に予算を寄せる。CPA 2万円未満の語（業務委託 高単価 13,685円、フリーランスエンジニア 転職 14,000円、flutter 16,967円、フリー ランス エンジニア 仕事 探し 18,691円、フリーランス エンジニア 案件 19,140円）を完全一致・フレーズ一致でも登録し、表示機会を増やす。
  5. 指名検索の目標CPAを分ける。指名は実績 10,778円なので、全体の目標値に引きずられないよう別キャンペーンに分けるか、グループ単位の目標を15,000円で固定する。
2〜6週目

ページとフォームを直す（CVRに最も効く部分）

  1. 広告グループごとの着地ページを用意。まず費用上位の3種類（案件探し・リモート・高単価）。ページ最上部の見出しを広告の約束と同じ言葉にする（例：「フルリモートのエンジニア案件」「月80万円以上の高単価案件」）。
  2. フォームを2段階に。1段階目はメールアドレスと得意な言語だけ。ふりがな・生年月日・パスワードは登録後に回す。
  3. スマートフォンでの表示を確認。クリックの72%がスマートフォンです。登録フォームが最初の画面に出るか、入力しやすいかを実機で確認する。
  4. リンク先の比較は「テスト」機能で。Google広告のキャンペーンのテスト（50%ずつ配信）で、登録ページ・トップページ・新ページを同時期に比べる。日付で切り替える方法は、今回のように結論が出ません。
並行して継続（3〜4週間サイクル）

クリエイティブを計画的に回す

  1. 主要3グループに広告を2本ずつ。訴求の切り口を大きく変えた2案を常に並べる（単価／リモート／スピード「最短1日」／非公開案件／転職との比較）。11/4の「転職・働き方比較」の切り口は有望なので、主力グループにも展開する。
  2. 判定ルールを先に決める。1案あたり表示3,000回または3週間で、クリック率と「表示あたりのコンバージョン」を比べ、負けた方を次の案に入れ替える。
